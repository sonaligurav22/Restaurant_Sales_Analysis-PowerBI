# Restaurant Sales Analysis using Power BI

## Project Overview
An interactive Power BI dashboard analyzing restaurant sales data over 15 days.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Dashboard Features
- Total Sales, Total Orders, and Total Quantity Sold
- Most and Least Sold Items
- Sales Contribution by Item
- Sales by Meal Type
- Top 3 and Bottom 3 Selling Items
- Unit Price vs Quantity Analysis
- Item Availability Across Meal Types

## Key Findings
- Total Sales: ₹46,820
- Total Orders: 351
- Total Quantity Sold: 573
- Tea was the highest-selling item by quantity.
- Chicken Biryani generated the highest sales among individual items.
- Lunch generated the highest sales among meal types.

## Business Recommendations
- Review low-selling items.
- Plan inventory according to meal-wise demand.
- Monitor item quantities to help reduce food waste.
- Analyze costs before making profit-related decisions.

**Note:** Sales revenue is not the same as profit.
